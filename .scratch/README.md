# Công việc tại dự án

Thư mục này chứa [đặc tả tổng thể CapMoney](capmoney-overall/spec.md) đã được Ninh xác nhận ở bước 7, file nguồn của [35 Story ứng viên](capmoney-overall/issues/) từ bước 8 và các spec, thiết kế, test spec, bằng chứng theo từng tính năng. Ninh đã duyệt [cách chia 35 lát](../docs/requirements/35-step-8-ticket-breakdown.md); các Story đã được chuyển và đối chiếu trên [Planio](https://tanninh.planio.com/projects/capmoney/issues). `Status: needs-triage` trong file nguồn là ảnh chụp lịch sử trước khi chuyển, không phải trạng thái hiện hành.

**Bước 9 về chức năng (16/10/2026):** CM-01 và CM-07–CM-09 đã có đặc tả và BA review trước đó; CM-10–CM-35 đã có spec 20 mục, Story, Q&A và handoff. [PM review CM-10–CM-35](capmoney-overall/step9-ba-review-2026-10-16.md) ghi `BA_READY` cho 25/26 Story; CM-26 còn chờ quyết định Q26.1 về bằng chứng xác minh khi hỗ trợ mất email. CM-02–CM-06 theo quy trình cũ và cần rebaseline kỹ thuật Java trước triển khai tiếp. `BA_READY` là chốt đặc tả chức năng, không thay `TECH_READY` hoặc nghiệm thu phần mềm.

Tính đến 16/10/2026, hạ tầng Java #47/#48 và CM-01.1 #43 đã có QA ticket. [CM-01](capmoney-manager-setup/story.md) đã có code #44/#45 và [handoff](capmoney-manager-setup/handoff.md), nhưng #44 còn chờ QA độc lập/PM, #45 còn chờ gate #44, code review và QA; Story còn T21 và thiết bị thật. Không suy `QA_PASS` từ code hay bằng chứng Dev. Các module khác vẫn đi qua gate theo [workflow](../docs/workflows/capmm-end-to-end.md). Quy ước tracker nằm ở [issue tracker](../docs/agents/issue-tracker.md); tổng quan code hiện chạy ở [project-overview](../docs/project-overview.md).
