# Tài liệu miền nghiệp vụ

CapMoney hiện dùng một ngữ cảnh. Agent đọc `GLOSSARY.md` ở gốc và ADR liên quan dưới `docs/adr/` trước khi viết đặc tả hoặc code. Nếu chưa có những file này, tiếp tục buổi tiếp nhận, không tạo tài liệu rỗng.

`domain-modeling` tạo hoặc cập nhật thuật ngữ khi ý nghĩa đã rõ. Glossary chỉ giải thích ngôn ngữ nghiệp vụ, không chứa thiết kế dữ liệu hay API. ADR chỉ dành cho quyết định khó đảo ngược, có đánh đổi thực sự và cần lưu lý do cho người sau.

Tên trong ticket, đặc tả, test và code phải thống nhất với glossary. Nếu một yêu cầu mới mâu thuẫn với ADR, nêu rõ mâu thuẫn để xem lại quyết định.
